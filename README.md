# 魔法のかけ算バトル

筆算でナビアンと戦いながら、かけ算の筆算をくり返し練習する小学生向けの算数Web教材です。

「問題を解く」だけでなく、筆算の手順を一つずつ確認しながら入力し、まちがえたところをやり直して、正確に計算する力を身につけることを目指しています。

## 公開ページ

[魔法のかけ算バトル](https://tt-sensei.github.io/magical-kakezan/)

## 学習できること

- かけ算の筆算の手順を理解する
- 一の位から順に計算する
- 繰り上がりを意識して計算する
- 筆算の数字を正しい位置にそろえて書く
- 2桁×1桁、2桁×2桁、3桁×2桁の計算に取り組む
- 自分の計算を見直し、まちがえた問題をやり直す

## かけ算レベル

レベルが上がるにつれて、扱う計算が難しくなります。

- Lv1：2桁×1桁
- Lv2〜Lv4：2桁×2桁
- Lv5：3桁×2桁

レベルごとに問題に取り組み、筆算の手順を確認しながら練習できます。

## バトルモード

### ノーマル

5問に挑戦し、5体のナビアンとのバトルを進めます。

ミスにはハートがあり、5回ミスするとゲームオーバーになります。

### タイムアタック

10問に挑戦し、時間と正解数に挑戦します。

短時間でたくさん解くことだけを目的にせず、正確に計算することも大切にした設計です。

## 筆算の学習画面

問題を表示して終わりではなく、筆算の途中を画面上で一つずつ入力します。

学習画面では、

1. かける
2. そろえる
3. 答え

という流れを確認しながら進めます。

数字キーパッドから入力できるため、タブレットでも操作しやすい構成です。

ヒントや「この問題をやりなおす」機能も用意しています。

## 学習記録

端末内に学習の記録を保存します。

- 正解数
- バトルの結果
- レベルごとの取り組み
- 修行の成果
- 宝石
- 称号
- バッジ・コレクション

などを確認できます。

## コレクション

学習を進めると、バッジなどのコレクション要素も楽しめます。

ゲーム要素は、問題数を減らしたり学習を置き換えたりするためではなく、継続して練習するきっかけとして使っています。

## ナビキャラとナビアン

ナビキャラとナビアンが登場する、ファンタジー風の算数学習教材です。

キャラクターとのバトルを入口にしながら、中心にあるのはあくまで「かけ算の筆算を正しく計算すること」です。

## 技術

- HTML
- CSS
- JavaScript
- localStorage

ブラウザだけで動作する静的なWeb教材です。

外部サーバー、データベース、バックエンドは使用していません。

## ファイル構成

```

```

## 動作環境

タブレット・パソコンのWebブラウザで利用できます。

インストールやアカウント登録は必要ありません。

学習記録は利用している端末のブラウザ内に保存されます。そのため、別の端末やブラウザへ自動的に引き継がれる仕組みではありません。

## 対象

小学生のかけ算・筆算の学習に。

特に、筆算の手順を確認しながら、くり返し練習したい場面を想定しています。
