# 魔法の筆算道場

かけ算の筆算を、レベル別の修行とゲーム要素で練習できる小学生向けの算数Web教材です。

## 公開ページ

[魔法の筆算道場を開く](https://tt-sensei.github.io/magical-kakezan/)

## 学べること

- かけ算の筆算の手順を確認する
- 繰り上がりに気をつけて計算する
- 2桁×1桁、2桁×2桁、3桁×2桁に取り組む
- 正確に計算する力と、最後まで取り組む力を伸ばす

## 修行レベル

- **Lv1**：2桁×1桁
- **Lv2〜Lv4**：2桁×2桁（難易度別）
- **Lv5**：3桁×2桁

## 主な機能

- 画面に書き込む形式の筆算入力
- 繰り上がりを意識できる入力欄
- レベル別の練習
- 修行の成果、宝石、称号の記録
- 魔法図鑑、メダル、バッジ、スタンプなどのおまけ要素
- 端末内への学習記録保存
